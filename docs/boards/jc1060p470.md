# GUITION JC1060P470

JC1060P470 是深圳市晶彩智能（GUITION）的 7 寸 ESP32-P4 屏幕板，PCB 背面丝印“guition JC1060P470”。它不是乐鑫的 ESP32-P4-Function-EV-Board，但是厂商的 ESP-IDF 示例用的就是那块板的 BSP（`espressif/esp32_p4_function_ev_board`），只改了功放、背光、屏幕复位和触摸的引脚以及屏幕参数。I2C、I2S 和 TF 卡的引脚厂商没有改，和本板原理图一致。

本文对应 `JC1060P470C_I_W`，内容来自“来源”一节固定版本的厂商资料包。引脚以原理图为准，并和厂商 BSP 的引脚定义核对过。

## 型号和版本

GUITION 用 JC1060P470 这个名字卖过不止一种板子。`JC1060P470C_I_W` 是黄色 PCB、没有外壳的那块，P4 是裸芯片，C6 是单独的模组，接外置天线；`JC1060P470N_I_W` 是它去掉触摸的版本。`JC1060P470C_I_W_Y` 是另一块板，带黑色外壳，主控换成了把 P4 和 C6 封在一起的 JC-ESP32P4-M3 模组，还多了以太网、RS-485 和 2×13 排针，引脚和本文不同。

屏幕也有新旧两版。据 espcontrol 的说明和 esphome-modular-lvgl-buttons 的 PR #127，2026 年起出货的新屏驱动 IC 仍然是 JD9165，但是初始化序列和时序都变了，用错了会白屏，并出现一条竖向的噪点带。新屏的外壳或包装上有 V2 标记，也可以看屏幕电路板上的四位日期码，2622 及以后是新屏。本文的屏幕参数来自上述资料包，对应旧屏。手上这块板使用旧屏配置。

## P4 芯片修订

原理图上 P4 是 QFN104 封装，引脚 54 标为 NC。按乐鑫的 v3.x 修订说明，v3.x 把引脚 54 改成了 VDD_HP_1，所以这块 PCB 是按 v1.x 设计的。手上这块板用 esptool v5.5.0 读出的芯片是 ESP32-P4 revision v1.0。

v1.x 在 ESP-IDF v6.1 里最高 360MHz，不作为项目的性能基线（见 `docs/product-design.md`），厂商规格书上写的 400MHz 要 v3.x 才能达到。v1.x 和 v3.x 的固件互不兼容，所以 `boards/jc1060p470/sdkconfig.defaults` 选了 `CONFIG_ESP32P4_SELECTS_REV_LESS_V3`，最低修订是 v1.0。项目配置为 CPU 360MHz、32MB PSRAM、PSRAM 时钟 200MHz。

## 功能和引脚

### 屏幕

屏幕是 7 寸 1024×600 IPS，MIPI DSI 2 lane，接 FPC1（0.5mm 30P）。屏幕复位是 GPIO27。背光由 MP3202 升压驱动，GPIO23 经 R15（0R）接 MP3202 的 EN，EN 上有 R16（10K）下拉，所以上电时背光是关的，调光是在 GPIO23 上输出 PWM。固件按厂商示例用的 ESP32-P4 Function EV Board BSP 选了 5kHz、10 位的 LEDC。MP3202 的手册不在资料里，EN 允许的 PWM 频率范围没有核对。DSI PHY 由 P4 片内的 LDO VO3 供电，厂商 BSP 把它设为 2500mV。

时序有两组来源，参数不同：

| 参数 | 厂商示例 | `jd9165-init.dtsi.txt` |
|---|---|---|
| 像素时钟 | 58MHz | 51.2MHz |
| HSYNC 宽度 | 40 | 24 |
| HBP | 160 | 136 |
| HFP | 160 | 160 |
| VSYNC 宽度 | 10 | 2 |
| VBP | 23 | 21 |
| VFP | 12 | 12 |
| 算出的帧率 | 约 64.97Hz | 约 59.99Hz |

厂商示例的 lane 速率是 550Mbps，像素格式用 RGB565，厂商说明里写了像素时钟高于 58MHz 时会出现白色条纹。两条 lane 合计 1100Mbps，而 58MHz 下 RGB565 需要 928Mbps，RGB888 需要 1392Mbps，所以这组参数下用不了 RGB888。dtsi 这组在 51.2MHz 下用 RGB888 也要 1228.8Mbps，同样超过了 1100Mbps。帧率是按“像素时钟 ÷（水平总长 × 垂直总长）”算的，P4 实际输出的像素时钟由分频得到，可能和设定值有出入。

项目保留 dtsi 初始化序列、同步宽度和后肩，配置为 2 lane 550Mbps、RGB565、VO3 2500mV。为接近 GB/GBA 的 59.7275Hz，像素时钟设为 48MHz，HFP 为 58，VFP 为 24，总周期为 `1242 × 647`。考虑 IDF 的 DSI 行计数取整，主机时序计算值约 59.7300Hz，DPI bridge 约 59.7331Hz。

屏幕模组规格书第 7 节 HV mode 给的范围是：像素时钟 44.9～63MHz（典型值 51.2MHz），水平总长 1200～1400，HSYNC 宽度 1～140，HBP 160，HFP 16～216，垂直总长 624～750，VSYNC 宽度 1～20，VBP 23，VFP 1～127。

厂商示例和 dtsi 的初始化序列命令和数据相同，区别只是厂商示例给最后的 0x11 和 0x29 各带了一个 0x00 参数。

### 触摸

GT911 经 FPC2（1.0mm 6P）接主板：1 脚 3.3V，2 脚 INT（GPIO21），3 脚 RST（GPIO22），4 脚 SCL，5 脚 SDA，6 脚 GND。I2C 和其他器件共用，见“I2C”。厂商说明里，GT911 报告的坐标范围是 800×480，示例在驱动里把 x 乘以 1024/800、y 乘以 600/480，换算到屏幕分辨率。

屏幕正对自己、USB 口朝右时，触摸与画面方向一致，不需要交换或翻转，只需按比例换算。项目 UI 以 USB 口朝下的竖屏方向显示，坐标换算见板级实现。

### 音频

ES8311 负责播放和录音，I2S 引脚如下：

| 信号 | GPIO |
|---|---|
| MCLK | 13 |
| BCLK | 12 |
| LRCK | 10 |
| P4 输出到 ES8311（播放） | 9 |
| ES8311 输出到 P4（录音） | 11 |

原理图里有几根线叫 ES7210_SCLK、ES7210_LRCK、ES7210_SDOUT，这是沿用下来的网络名。板上没有 ES7210，GPIO11 接的是 ES8311 的 ASDOUT。

ES8311 的差分输出经 NS4150 放大后接喇叭座 CN3（MX1.25 2P），是单声道。NS4150 的使能脚接 GPIO20（PA_CTRL），有 R86（10K）下拉，默认关闭。NS4150 由 IP5306 的 5V 输出 VOUT-BAT 供电，项目按 5V 设置 codec 的 `pa_voltage`；功放本身的增益从图纸上看不出来，没有计入。GPIO20 在板子初始化时设为输出低电平，codec 打开以后才拉高。GB 的立体声先把左右声道平均再送给喇叭。麦克风 MIC1 接 ES8311 的 MIC1P 和 MIC1N。

### TF 卡

TF 卡用 SDMMC 4 位模式：D0～D3 是 GPIO39～42，CLK 是 GPIO43，CMD 是 GPIO44。卡的 VDD 和数据线上的 5.1K 上拉都接 P4 片内的 LDO VO4，所以软件要先打开 VO4 才能用卡，厂商 BSP 用 `sd_pwr_ctrl_new_on_chip_ldo()` 打开通道 4。卡座的 CD 脚没有接，没有插卡检测。

### 按键和扩展口

板上有三个按键：SW3 是 BOOT，接 GPIO35；SW2 是复位，接 CHIP_PU；SW1 接 IP5306 的 KEY。

游戏按键可以接在两个 0.5mm 14P 的扩展 FPC 上。下面的脚号按原理图：

| FPC3 脚号 | 信号 |
|---|---|
| 1、2 | GND |
| 3～6 | GPIO45～48 |
| 7 | GPIO5 |
| 8 | GPIO4 |
| 9 | GPIO3 |
| 10 | GPIO2 |
| 11 | I2C SCL（GPIO8） |
| 12 | I2C SDA（GPIO7） |
| 13、14 | 3.3V |

| FPC4 脚号 | 信号 |
|---|---|
| 1、2 | GND |
| 3～5 | 不接 |
| 6～12 | GPIO28～34 |
| 13、14 | 3.3V |

两个口一共引出 15 个空闲 GPIO。`docs/product-design.md` 里的按键有方向键 4 个，再加 A、B、Start、Select、菜单键和预留的 L、R，一共 11 个，每个键单独占一个 GPIO 也够用。GPIO34 是 P4 的 strapping 脚（P4 数据手册“Strapping 管脚”一节），接按键时要注意它在复位时的电平。

CN4（SH1.0 4P）也引出了 I2C：1 脚 GND，2 脚 3.3V，3 脚 SCL，4 脚 SDA。

### I2C

GPIO7（SDA）和 GPIO8（SCL）是板上唯一一组 I2C，接了 ES8311、GT911、RX8025T 和摄像头座 FPC5，也引到了 FPC3 和 CN4。上拉有两组，都接 3.3V：R53、R54 是 5.1K，R43、R44 是 2.2K。

| 器件 | 7 位地址 |
|---|---|
| ES8311 | 0x18。CE 经 R75（10K）接地，按 ES8311 手册，CE 为低时地址是 0x18 |
| GT911 | 0x5D 或 0x14，由复位时 INT 的电平决定（GT911 数据手册） |
| RX8025T | 0x32（Epson RX-8025T 应用手册） |

### RTC

RX8025T 的 VDD 由 3.3V 和 CR1220 纽扣电池（BT1）经 BAT54C 二选一供电，所以装了电池时，整板断电后它还能继续走时。手上这块板的 BT1 没有装电池，断电以后时间会丢失。它的 INT 脚只接了 R87（10K）上拉，没有接到 P4。

使用 RTC 时间前需要检查日期和 VLF。按 RX-8025T 应用手册 8.2.3，VLF 置位以后所有寄存器的内容都不确定，要全部重新设置。

设置时间时要注意下面几点，节号都是应用手册的：

- 手册没有给出设置时间的步骤。0Fh 的 RESET（bit 0）写 1 时，一秒以下的计数停住清零，收到 I2C 的 STOP 条件时 RESET 自己变回 0（8.2.2）。项目从 0Fh 开始，一次写入控制寄存器和 00h～06h 的时间，地址从 0Fh 回绕到 00h（8.6），时钟从这次传输结束时开始走。
- 0Dh 的 TEST（bit 7）不能写 1（8.2.4）。VLF 置位以后，项目把 0Dh 写成 00h，0Fh 写成 40h，也就是默认的 2 秒温度补偿间隔，中断全部关闭。
- 星期在 03h，是独热码，bit 0 是星期日（第 12 页）。
- 0Eh 的标志只能写 0（第 7 页）。手册没有说振荡器起振之前能不能清掉 VLF，起振时间最长 3 秒（第 6 节），所以要清到读回 0 为止，并限制次数。
- 一次 I2C 传输要在 0.95 秒内结束（8.6）。

### 电池

IP5306 管锂电池的充电和放电升压。电池接 CN1（MX1.25 2P），IP5306 输出的 VOUT-BAT 给整板供电。电池电压经 R2（68K）和 R6（100K）分压后接 GPIO52，GPIO52 上的电压是电池电压的 100/168，约 0.595 倍，电池 4.2V 时约 2.50V。

### USB 和串口

三个 Type-C 口的 VBUS 并在一起，哪个口都能给板子供电。

| 原理图 | 连接 |
|---|---|
| USB1 | CH340C 转 UART0（GPIO37 TXD、GPIO38 RXD）。CH340C 的 DTR、RTS 经 Q2、Q3 控制 BOOTMODE（GPIO35）和 CHIP_PU，esptool 可以自动进下载模式。厂商要求用这个口烧录，规格书接口图里标 UART 的那个 Type-C 口就是它 |
| USB2 | P4 的 USB 1.1 全速口，GPIO24 是 D-，GPIO25 是 D+ |
| USB3 | P4 的 USB 2.0 高速 OTG，用专用引脚 |

UART0 也引到了 CN2（MX1.25 4P）：1 脚 5V，2 脚 TXD，3 脚 RXD，4 脚 GND。

### Wi-Fi 和 BLE

C6 通过 4 位 SDIO 接 P4，跑 ESP-Hosted：

| 信号 | P4 | C6 |
|---|---|---|
| CMD | GPIO19 | IO18 |
| CLK | GPIO18 | IO19 |
| D0 | GPIO14 | IO20 |
| D1 | GPIO15 | IO21 |
| D2 | GPIO16 | IO22 |
| D3 | GPIO17 | IO23 |
| 复位 | GPIO54 | EN |
| | GPIO6 | IO2 |

C6 的 EN 有 R59（10K）上拉和 C82（1µF）电容。CN5（6P）引出了 C6 的 UART0、IO9 和 EN，用来单独给 C6 烧录。

P4 的 SDMMC 控制器有两个 slot。TF 卡用的 GPIO39～44 是 slot 0 的 IO MUX 引脚，C6 用的 GPIO14～19 不是，只能经 GPIO 交换矩阵接 slot 1，所以 TF 卡和 C6 分别用 slot 0 和 slot 1。两个 slot 共用一个控制器，控制器一次只能执行一条命令。

### 摄像头和 RGB 灯

FPC5（1.0mm 15P）是 MIPI CSI 2 lane 摄像头座，I2C 和上面共用。WS2812 的数据脚接 GPIO26。

## 电源

USB 的 5V 进 IP5306，IP5306 输出 VOUT-BAT。VOUT-BAT 一路经 TLV62569（U2）降到 3.3V，另一路直接给 NS4150 和背光的 MP3202 供电。U3（TLV62569）从 3.3V 降压，给 P4 的 VDD_HP 供电，它的 EN 和 FB 接 P4 的 EN_DCDC 和 FB_DCDC。厂商规格书写的功耗约为 5V 600mA，厂商的烧录说明也要求电源能提供 600mA 以上。

P4 片内 LDO 的接法决定了软件要打开哪几路：

| LDO | 接到 | 说明 |
|---|---|---|
| VO1 | VDD_FLASH（经 R38 0R） | flash 供电。ESP-IDF v6.1 的默认配置把通道 1 设为 3300mV |
| VO2 | 引脚 59 和 67 | 原理图上标的是 VDDPST，P4 数据手册里这两个脚是 VDD_PSRAM_0 和 VDD_PSRAM_1，给片内 PSRAM 供电。ESP-IDF v6.1 的默认配置把通道 2 设为 1800mV |
| VO3 | VDD_MIPI_DPHY（引脚 41） | 厂商 BSP 设为 2500mV |
| VO4 | VDDPST_5（引脚 85），TF 卡的 VDD 和上拉 | 引脚 85 是 GPIO39～48 的 IO 电源。厂商 BSP 用通道 4 给 TF 卡供电 |

P4 的 GPIO 按电源脚分成几组，分组见 P4 数据手册的管脚表。这块板上，除了引脚 85，其他 GPIO 的电源脚都接 3.3V，所以 GPIO0～38 和 GPIO49～54 是 3.3V IO，扩展口 FPC4 上的 GPIO28～34 也在其中。GPIO39～48 的 IO 电压就是 VO4 的电压，VO4 没有打开时这一组用不了。扩展口 FPC3 上的 GPIO45～48 在这一组里，接按键时要先打开 VO4，并设成 3.3V。因为 TF 卡也接在 VO4 上，所以 TF 卡切到 1.8V 的 UHS-I 模式时，GPIO45～48 也会变成 1.8V。
