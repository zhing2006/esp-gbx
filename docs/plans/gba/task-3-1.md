# 任务 3-1：最小可运行版本

这是[路线图](../../roadmap.md#gba) GBA 段里程碑 3 的唯一任务：让正式固件能从菜单启动 GBA 游戏，显示画面、响应按键，卡带存档可靠写回，两个后端都能运行。这个版本还没有声音，声音在里程碑 5；即时存档在里程碑 4。做完这个任务，里程碑 3 就达到了完成标准。这个任务依赖 2-6。

开工时在[任务状态](status.md)里把这个任务标为“进行中”。

## 先读

- 路线图 GBA 段开头的几段和里程碑 3，[产品设计](../../product-design.md)的“范围”“SD 卡目录”“卡带存档”和“音画同步”。
- [架构](../../architecture.md)的“显示和触摸”“运行游戏”和“菜单、设置和存档”。
- [UI 布局](../../ui-layouts/index.md)，尤其是各板的 GBA 效果图、“指示灯和拨杆”和“触摸”，以及[调试设计](../../debug-design.md)的“游戏时常驻的信息”。
- GB 段的 [3-2](../gb/task-3-2.md) 和 [3-3](../gb/task-3-3.md)，以及 2-4 的存档接口。

## 范围

- 菜单扫描 `roms/` 时按 ROM 头识别 GBA 游戏（GBATEK “GBA Cartridge Header”），不看扩展名。ROM 列表和载入用同一个判断。
- 启动 GBA 游戏之前检查卡上的 BIOS，按 1-1 记下的校验值核对。没有 BIOS 或者校验不符时，游戏不启动，用提示框说明原因，并记入故障列表。GB 和 GBC 游戏不受影响。
- `Game` 能运行 GBA 的系统。模拟任务仍然独占系统、固定在 core 1，加载、复位、按帧运行、选后端、暂停和退出都和 GB 走同一套流程。GB 和 GBC 的行为和速度不能变。
- 画面经过 `FrameSink` 交给显示的游戏层，按放得下的最大整数倍放大，`SCALING` 的两种方式照常生效。
- 触摸控件和串口控制台的按键映射到 GBA 的按键，包括 L 和 R。玩 GB 和 GBC 游戏时 L、R 的外观和行为不变。
- 没有声音输出，运行节奏按墙钟的帧周期控制，做法见架构文档“运行游戏”中的“节奏”。`AUDIO` 格的显示和 2X 时相同。
- 卡带存档按产品设计“卡带存档”一节写回：脏标记、延迟写回、退出时立即提交，两份文件轮流写。存档文件记录存档类型和容量，载入已有的存档时把它们交给系统，没有存档文件时用 2-4 的自动判断。没有存档芯片的游戏不创建存档文件。
- 游戏页亮 GBA 灯，执行后端、存档和错误的指示灯照常工作，`SPEED`、`FRAME` 和 `MEM` 按调试设计显示。
- 设置：PALETTE 和颜色校正对 GBA 游戏不起作用，GBA 游戏运行时显示为灰色。暂停菜单的即时存档和读档在 4-1 之前对 GBA 游戏显示为灰色。

## 不做

- 声音和音频输出，这在 5-1。
- 卡带 RTC，这在 5-2。
- 即时存档，这在 4-1。
- 2X，这在 6-2。速度拨杆拨到 2X 时，GBA 游戏仍然按 1X 运行，`SPEED` 不显示 `FAST`。
- 手动指定存档类型。

## 约束

- 写代码时就要注意性能，解释器和 JIT 都一样。在满足功能的前提下选性能最好的实现，不写明显低效的代码，也不留给以后的优化任务再改。
- 写卡不在模拟所在的核上进行，不阻塞模拟。
- 改动 app、游戏层和菜单的共用代码时，GB 和 GBC 的游戏照常运行。开发期间不运行 GB 和 GBC 的测试。按路线图 GBA 段的规则，收尾时运行这个里程碑改到的共用代码影响的 GB 和 GBC 测试，只判定结果；改到两个系统共用的热代码时，用同一组 GB ROM 比较里程碑前后两个后端的速度。没有影响就不运行。
- 开发期间只构建 `sila_p4-release` 和 PC 的 debug 版，需要上板测试时才构建测试固件。上板试玩时列出检查点，由用户操作和判断，不为每个检查写脚本。
- 按 `cmake/core_layout.cmake` 的规则检查热代码的位置。

## 由你决定

`Game` 怎样同时支持两种系统、存档文件里类型和容量的格式，以及 BIOS 的检查放在载入的哪一步。选择的理由写在代码注释里，模块边界写进架构文档。

## 完成标准

- 在 Sila P4 上用两个后端试玩 GBA 游戏，游戏由用户提供，不提交。用相同的 ROM、输入和统计区间记录 `SPEED` 和 `FRAME` p95，以及板型、芯片修订和主频。能不能达到原速以实测为准。
- 试玩的游戏覆盖 SRAM、Flash 和 EEPROM 三类存档，退出并重启以后都能读回存档。在写卡带存档的过程中断电一次，重启以后能读到上一份有效存档。
- 卡上没有 BIOS 和 BIOS 校验不符时，GBA 游戏都不启动，并显示原因。
- GBA 的固定回归通过；里程碑 3 影响到的 GB 和 GBC 测试通过，没有影响就不运行。
- 里程碑结束，PC 的 debug 构建和全部板子的正式固件、测试固件各构建一次，没有新的警告。

## 收尾

- 满足全部完成标准以后，在[任务状态](status.md)里把这个任务标为“已完成”。
- 在架构文档中写明 `Game` 和存档对 GBA 的支持，产品设计和 UI 布局里有变化的地方同步修改。实测数据保存在报告里。
- 向用户汇报试玩的结果、`SPEED` 和 `FRAME` 的实测值，以及发现的问题。
