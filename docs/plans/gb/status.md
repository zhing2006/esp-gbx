# 任务状态

本文记录[路线图](../../roadmap.md#gb) GB 段各里程碑拆出的任务做到了哪一步。任务的内容见各自的计划文件。

状态只有三种：未开始、进行中、已完成。开工时把任务改成“进行中”。任务文件里的完成标准全部满足以后，才能改成“已完成”；只做完一部分时保持“进行中”，并在说明栏写还差什么。依赖的任务还没有完成时，不要开始这个任务。

说明栏只写当前的阻塞和等用户确认的事项，不写工作过程。
